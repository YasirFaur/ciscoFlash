BID (Bridge ID)

BID stands for Bridge ID in Cisco Spanning Tree Protocol. Switches use this unique identifier to elect the Root Bridge for the network. It consists of a priority value, an optional VLAN ID, and the switch MAC address. The default bridge priority on Cisco switches is set to 32,768. During elections, the switch with the lowest BID value becomes the Root Bridge. Administrators can lower the priority to manually select a specific switch. Overall, BID ensures a systematic election process to prevent switching loops.
