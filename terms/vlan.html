VLAN (Virtual Local Area Network)

VLAN stands for Virtual Local Area Network in computer networking. It splits a single physical network into multiple logical networks. Devices on different VLANs cannot talk to each other without a router. This design improves network security by isolating sensitive data traffic. It also reduces network congestion by limiting broadcast traffic to small groups. Network administrators can easily organize users by department instead of physical location. Overall, VLANs make managing large networks safer, faster, and more efficient.

Configuration Example (Cisco IOS)


    Switch(config)# vlan 10
    Switch(config-vlan)# name Sales
    Switch(config-vlan)# exit
    Switch(config)# interface fastethernet 0/1
    Switch(config-if)# switchport mode access
    Switch(config-if)# switchport access vlan 10
